# Skill 市场与图片水印迁移设计

## 目标

第一阶段把 lawhub 仍在使用的 Skill 市场和图片水印迁入模型站点，先保证模型站点功能完整可用。暂不改 LawyerCopilot，不停 lawhub，不关闭旧域名。

## Skill 市场

- 模型站点保存每个 Skill 的当前版本，不迁历史版本。
- `skills`（技能表）保存名称、显示名、说明、公开/私有状态、当前版本、ZIP 内容、内容哈希、作者名和时间。
- `skill_user_access`（私有技能用户授权表）保存 Skill 与模型站点用户的多对多授权。
- 管理员可新增、更新、删除 Skill，切换公开/私有，并勾选可查看私有 Skill 的具体用户。
- 普通用户可查看全部公开 Skill，以及管理员明确授权给自己的私有 Skill。
- 管理员可查看全部 Skill。
- 下载前再次执行可见性判断，不能只依赖页面隐藏。
- 保持 `/api/skills`（技能接口）路径和带版本号的下载地址，后续桌面端迁移时减少改动。

## 数据迁移

- 一次性导入工具读取 lawhub 导出的当前版本 JSON，写入模型站点数据库。
- 保留原 Skill 编号、名称、当前版本、ZIP 原文、内容哈希、公开/私有状态和作者名。
- 私有 Skill 导入后默认只对管理员可见，由管理员在模型站点重新指定用户。
- 导入使用事务；内容哈希不一致、编号或名称冲突时整批失败，不留下部分数据。
- 第一阶段不生成额外备份，不删除 lawhub 数据。

## 图片水印

- 公开路由 `/tools/watermark`，无需登录。
- 图片仅在浏览器本地通过 Canvas 处理，不上传服务器。
- 支持 JPG、PNG、WebP 批量导入，文字或图片水印，单点或平铺，位置、大小、透明度、旋转和间距调整，实时预览，ZIP 下载。
- 从已验证的 lawhub 实现原样迁移计算与交互，按模型站点路由和样式接入。

## 页面

- 登录后的侧栏增加“Skill 市场”和“图片水印”。
- Skill 市场以卡片展示名称、说明、作者、公开状态和版本；管理员看到维护入口和用户授权控件。
- 图片水印保留独立公开页面，不依赖模型站点账号状态。

## 验证

- 后端测试覆盖：公开/私有可见性、管理员权限、用户授权、下载权限、版本更新、导入事务和哈希校验。
- 前端测试覆盖：路由、列表、管理员维护、用户授权和水印核心行为。
- 生产构建通过后，本地启动模型站点，分别以匿名、普通用户、获授权用户和管理员身份验收。
- 实际迁移时核对 Skill 总数、公开/私有数量、各 Skill 编号/版本/内容哈希；全部一致后才进入桌面端改造阶段。
